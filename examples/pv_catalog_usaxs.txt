# PV catalog -- USAXS / 12-IDE
#
# Channel Access has no name-search protocol, so `epics_pv_search` searches
# this file instead. It has a second job that matters more: it gives the
# model human-readable names for cryptic records, so it can answer "what is
# the guard slit vertical size?" without the user knowing that the answer
# lives in usxLAX:GSlit1V:t2.C.
#
# Format: one entry per line,  PV<whitespace>description
# Blank lines and lines starting with # are ignored.
# A PV listed here is NOT thereby allowed -- the policy file is the only
# thing that grants access. Listing an unreachable or denied PV is harmless.
#
# The entries below are drawn from aievaluator's instrument checks
# (aievaluator/config/instrument_usaxs.yaml). Extend freely; this file is
# documentation, not a boundary.
